SWAADGO - Codemagic APK Build

1. Upload the files in this project to the ROOT of your GitHub repository.
2. Make sure codemagic.yaml and gradlew are at the repository root.
3. In Codemagic, open SWAADGO.
4. Click "Check for configuration files".
5. Select the "swaadgo-android-debug" workflow.
6. Start a build.
7. After a successful build, download:
   app/build/outputs/apk/debug/app-debug.apk

This is a DEBUG APK for phone testing. It does not require Google Play publishing.
